## Project Overview

This repository contains 10 beginner-friendly Python case studies
prepared for the Python Activity-Based Learning assignment. Each program
demonstrates fundamental programming concepts such as variables, data
types, conditional statements, loops, strings, lists, nested lists, and
tuples.

## Case Studies

1.  **Attendance Recovery Computation (`python1.py`)**\
    Calculates current attendance percentage and determines the minimum
    number of consecutive classes a student must attend to reach the 75%
    requirement.

2.  **ATM Transaction Sequence Simulation (`python2.py`)**\
    Simulates deposits and withdrawals, validates transactions, and
    displays the final account balance and transaction counts.

3.  **Student Performance Trend Analysis (`python3.py`)**\
    Accepts examination marks, calculates changes between examinations,
    identifies the highest mark, and reports the overall trend.

4.  **Advanced Numeric Pattern Generator (`python4.py`)**\
    Prints a numeric diamond pattern for a valid size from 1 to 9.

5.  **Repeated Transaction Detection (`python5.py`)**\
    Identifies transactions with duplicate IDs or amounts above a
    specified threshold.

6.  **String-Based Examination Answer Evaluation (`python6.py`)**\
    Compares student answers with an answer key and calculates correct,
    incorrect, unanswered, and final scores.

7.  **Text Compression Using Character Runs (`python7.py`)**\
    Compresses consecutive repeated characters using run-length encoding
    and compares the original and encoded lengths.

8.  **Student Marks Matrix Analysis (`python8.py`)**\
    Analyses a marks matrix to calculate student totals and averages,
    subject averages, and the top-performing student.

9.  **Tuple-Based Product Catalogue Audit (`python9.py`)**\
    Calculates product inventory values, flags products that need
    replenishment, and reports the total inventory value.

10. **Food Waste Monitoring System (`python10.py`)**\
    Calculates daily leftovers and food-waste percentages, then warns
    when waste exceeds the chosen threshold.

## Concepts Demonstrated

## How to Run the Programs

1.  Install Python 3 on your computer.

2.  Download or clone this repository.

3.  Open the repository folder in Visual Studio Code or a terminal.

4.  Open a terminal in that folder.

5.  Run one program at a time, for example:

    ``` bash
    python python1.py
    ```

    Replace `python1.py` with `python2.py`, `python3.py`, and so on, to
    run another case study.

6.  Enter the requested input when the program prompts you.

On some Windows systems, use `py python1.py` if the `python` command is
not recognised.
